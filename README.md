# NammaSpace 🏢

### Intelligent Indoor Digital Twin & Navigation Platform

NammaSpace is a browser-based indoor mapping and navigation prototype.

## Features
- Interactive Three.js 3D environment
- First-person navigation
- Indoor POI search
- A* pathfinding
- Obstacle-aware routing
- Photo and video uploads
- GLB 3D model loading

## Technology Stack
- Python
- FastAPI
- Three.js
- JavaScript
- A* Pathfinding

## Run in Termux

Install dependencies:

pip install fastapi uvicorn python-multipart numpy

Start the application:

./start.sh

Open:

http://127.0.0.1:8000

## Project Status
MVP prototype. Automatic photogrammetric reconstruction is planned for a future release.
